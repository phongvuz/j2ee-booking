# Backend

Thư mục quản lý mã nguồn backend của dự án đặt vé xe.
Hiện chỉ có khung thư mục, chưa có ứng dụng backend để chạy.

- `src/`: mã nguồn ứng dụng.
- `tests/`: kiểm thử backend.
- `docs/`: tài liệu API, cơ sở dữ liệu và triển khai.

Khi chọn công nghệ, đặt cấu hình build và dependencies tại `BE/`, điều chỉnh
cấu trúc theo framework và bổ sung hướng dẫn chạy tại đây.
Nếu dùng Java/J2EE, có thể dùng `src/main/java`, `src/main/resources`
và `src/test/java` theo quy ước của công cụ build.

Không commit mật khẩu hoặc tệp môi trường chứa thông tin bí mật.
